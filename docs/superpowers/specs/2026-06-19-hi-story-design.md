# hi story — 小说写作辅助工具 设计文档

> 版本: v1.0 | 日期: 2026-06-19 | 状态: 设计中

---

## 1. 产品概述

**hi story** 是一个本地优先的桌面端小说写作辅助工具，覆盖从构思到完稿的全流程。每本小说作为一个独立的「创作会话」，整合大纲、角色、世界观、章节写作、AI 对话、文学数据库与灵感搜索，所有数据存于本地 SQLite。

### 1.1 核心定位

- **本地优先** — 数据不依赖云端，离线可用，隐私可控
- **AI 可选** — 联网时 AI 深度辅助，断网时核心写作功能完整
- **文学地基** — 内置五层文学/历史/神话数据库，创作有据可依
- **贯通设计** — 角色 ↔ 大纲 ↔ 世界观 ↔ 章节 之间自由关联，上下文随行

### 1.2 目标用户

- 中长篇小说创作者（中文为主，也支持多语言）
- 创作类型涵盖：历史、宫斗、仙侠、玄幻、武侠、西幻、恐怖、言情
- 需要 AI 辅助构思但保持创作主导权的作者

## 2. 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| **桌面壳** | Electron | 成熟稳定，Windows 兼容性好，文件/菜单/快捷键支持完善 |
| **渲染层** | React + TypeScript | UI 框架 |
| **编辑器** | TipTap / ProseMirror | 所见即所得 + Markdown 快捷键混合方案 |
| **本地存储** | SQLite (better-sqlite3) | 全文索引 (FTS5)、对话持久化、项目数据 |
| **AI 层** | Provider 抽象层 | 多 Provider 支持（Claude、GPT 等），按需切换 |

## 4. 功能模块

### 4.1 小说项目管理

- 创建/打开/删除小说项目
- 每本小说拥有独立的数据空间（角色、大纲、世界观、章节、对话、素材）
- 项目元信息：书名、类型标签、风格、简介
- 数据导入/导出（备份、迁移）

### 4.2 大纲模块

- 树形大纲结构，节点可自由拖拽排序、嵌套
- AI 仅参与概述层面的补充（不会代写正文）
- 大纲节点可关联角色、世界观条目
- 大纲视图：树形 / 卡片看板 两种展示模式

### 4.3 角色模块

- 角色卡片：名称、外貌、性格、背景、弧线、关系图谱
- 角色关系图可视化（力导向图）
- 角色 ↔ 章节关联（标记角色在哪些章节出场）
- 角色 ↔ 角色关联（父母、恋人、仇敌、师徒等）
- AI「角色设计师」Prompt 模板，辅助角色设定完善

### 4.4 世界观模块

- 世界观条目：地点、势力、种族、法则、历史、文化
- 条目之间可建立层级关系（如：天剑宗 → 北疆 → 雪域）
- AI「世界观规划师」Prompt 模板，从一句话深入发散完整设定
- 世界观 ↔ 章节关联（标记设定在哪些章节体现）
- 世界观 ↔ 角色关联（角色属于哪个势力/地点）

### 4.5 写作模块

- 所见即所得富文本编辑器，支持 Markdown 快捷键
- 章节管理：新建、排序、草稿/定稿状态
- 字数统计、写作目标追踪
- AI 参与度控制：
  - **零参与**：纯编辑器模式
  - **辅助参与**：AI 文笔编辑（润色/建议/避免重复用词）
  - **深度参与**：AI 续写建议（用户控制是否采纳）

### 4.6 AI 对话模块

- **核心设计**：每本小说是一个独立的创作会话，内可创建多个对话线程
  - 线程分类示例：「角色讨论」「情节构思」「世界设定」「日常交流」
- **上下文自动构建**：每次 AI 调用自动注入：
  - 小说元信息（书名、类型、风格）
  - 当前编辑的章节信息
  - 关联的角色卡片
  - 关联的世界观条目
  - 关联的大纲节点
  - 最近的对话历史摘要
  - 用户当前选中的文字
- **角色预设 Prompt 模板**：
  - 「世界观规划师」— 专注设定完善
  - 「角色设计师」— 专注角色塑���
  - 「情节参谋」— 专注剧情走向
  - 「文笔编辑」— 专注语言润色
  - 「灵感助手」— 综合搜索参考
  - 支持用户自定义
- **对话持久化**：
  - 无条数/字数限制，受限仅硬盘空间
  - 支持单条删除、批量清空
  - 对话历史可全文搜索
- **Provider 抽象层**：
  - 支持多 AI 服务（Claude、GPT 等）
  - 流式响应
  - API Key 本地加密存储
  - 用量统计

### 4.7 文学数据库（五层）

#### 4.7.1 公版文学层 (~200MB)

| 内容 | 来源 |
|------|------|
| 四大名著（红楼梦/三国演义/水浒传/西游记） | 公开数字资源 |
| 唐诗宋词全集（约5.5万首） | chinese-poetry (GitHub) |
| 古文观止 | 公开数字资源 |
| 三言二拍、聊斋志异、封神演义 | 公开数字资源 |
| 世界经典小说（战争与和平/基督山伯爵/福尔摩斯等） | Project Gutenberg |

#### 4.7.2 历史军事层 (~100MB)

| 类别 | 内容 |
|------|------|
| 📜 中国史/政斗 | 《史记》精选、《资治通鉴》精选、《战国策》、二十四史名篇 |
| ⚔️ 兵法/战争 | 《孙子兵法》、《三十六计》、《吴子兵法》、古代战役实录 |
| 🏛️ 西方历史/神话 | 希腊神话体系、北欧神话体系、凯尔特/亚瑟王传奇、欧洲中世纪战争史、罗马帝国兴衰、十字军东征、百年战争/拿破仑战争 |

#### 4.7.3 神话志怪层 (~120MB)

| 类别 | 内容 |
|------|------|
| 🦊 东方志怪 | 《聊斋志异》、《搜神记》、《山海经》、《子不语》、《阅微草堂笔记》、《酉阳杂俎》、《封神演义》、《西游记》 |
| 🐙 西方超自然 | 克苏鲁神话 (Lovecraft)、哥特文学、吸血鬼/狼人传说考据、中世纪恶魔学、炼金术/魔法神秘学文献 |

#### 4.7.4 词典/修辞层 (~80MB)

| 内容 | 说明 |
|------|------|
| 成语词典（约5万条） | 含出处、释义、例句 |
| 现代汉语词典 | 词汇释义 |
| 古汉语字典 | 文言词汇 |
| 近义词/反义词库 | 避免重复用词 |
| 修辞手法大全 | 比喻/拟人/排比/通感等 |
| 描写分类词汇库 | 按情绪/场景/动作分类的描写素材 |

#### 4.7.5 用户导入层（无上限）

- 在线小说链接导入，全文持久存储
- 支持两种来源：
  - **开放网站**：直接抓取全文
  - **需登录平台**（如起点、晋江等）：提示用户手动粘贴或提供 Cookie
- 手动素材收集：文字摘录、笔记、灵感碎片
- 支持打标签、关联到特定小说/角色/章节

### 4.8 灵感搜索模块（可开关）

#### 4.8.1 触发方式

- 在编辑器中选中文字 → `Ctrl+Shift+I` / 右键菜单 / 工具栏按钮
- 面板从右侧滑出，宽度可拖拽调整（默认 400px）
- 关闭：`Esc` / 点击面板外 / 再次按快捷键

#### 4.8.2 搜索流程

```
选中文字 → 提取关键词
              │
              ├→ 公版文学层 FTS5 → 候选1
              ├→ 历史军事层 FTS5 → 候选2
              ├→ 神话志怪层 FTS5 → 候选3
              ├→ 词典修辞层 FTS5 → 候选4
              └→ 用户导入层 FTS5 → 候选5
              │
              ▼
         合并候选 → AI 语义精排（可配置开关）
              │
              ▼
         结果展示 + AI 写作建议（可选项）
```

#### 4.8.3 搜索结果展示

- 按来源分层展示（📚公版 / 📜历史 / 🦊志怪 / 📖词典 / 👤用户）
- 每条结果显示：出处、相似度评分、相关原文片段
- 操作：展开原文 / 复制引用 / 添加到素材库 / 发送到 AI 对话

#### 4.8.4 面板行为

- 可关闭：不触发时不占用空间
- 触发后保持打开，直到用户关闭
- 多次搜索在面板内以标签页形式累积，方便对比

## 5. 数据模型

### 5.1 核心实体

```
Project (小说项目)
  ├── id, name, type_tags, style, summary, created_at, updated_at
  │
  ├── OutlineNode (大纲节点)
  │     id, project_id, parent_id, title, summary, sort_order, ai_participation_level
  │
  ├── Character (角色)
  │     id, project_id, name, aliases, appearance, personality, background, arc
  │     relationships: [{target_character_id, type, description}]
  │
  ├── WorldEntry (世界观条目)
  │     id, project_id, parent_id, category(place/faction/race/law/history/culture)
  │     name, description, sort_order
  │
  ├── Chapter (章节)
  │     id, project_id, title, content(rich text), status(draft/final), word_count
  │     sort_order, created_at, updated_at
  │
  ├── ConversationThread (对话线程)
  │     id, project_id, title, category, created_at
  │     messages: [{role, content, timestamp, related_entities: [...]}]
  │
  ├── Material (素材)
  │     id, project_id, source_type(public_domain/history/myth/dict/user)
  │     title, content, url, tags, created_at
  │
  └── ReferenceLink (关联关系 - 多对多映射表)
        source_type, source_id, target_type, target_id, relation_type
```

### 5.2 关联关系矩阵

| 关系 | 说明 |
|------|------|
| Character ↔ Chapter | 角色在哪章出现 |
| Character ↔ OutlineNode | 角色弧线对应的剧情节点 |
| Character ↔ Character | 角色之间的关系 |
| Character ↔ WorldEntry | 角色属于哪个势力/地点 |
| WorldEntry ↔ Chapter | 设定在哪章体现 |
| WorldEntry ↔ OutlineNode | 世界观对应的大纲节点 |
| Message ↔ AnyEntity | 对话消息讨论的对象 |
| Material ↔ AnyEntity | 素材关联到哪个角色/章节/大纲 |

## 7. AI 参与度分级

| 场景 | AI 参与度 | 说明 |
|------|----------|------|
| 章节正文写作 | 零 / 按需辅助 | 默认关闭，用户手动触发才介入 |
| 大纲 | 概述层 | AI 补充大纲框架和走向，不写具体正文 |
| 世界观 | 深度参与 | AI 从一句话设定发散出完整细节 |
| 角色设计 | 辅助参与 | AI 提供建议，用户决策 |
| AI 对话 | 完全开放 | 用户和 AI 自由讨论任何创作话题 |
| 灵感搜索 | 可配置 | 关键词匹配始终可用，AI 语义精排可选开关 |
| 文笔润色 | 按需触发 | 用户选中文字后手动触发 AI 润色建议 |

## 8. 数据隐私与性能

### 8.1 隐私

- 所有用户数据（小说内容、角色、对话）存于本地 SQLite
- AI API Key 本地加密存储，不上传任何第三方
- 文学数据库（公版层）打包在应用内
- 用户选择导入的在线小说存于本地

### 8.2 性能目标

- 应用冷启动 < 3 秒
- 单个小说项目支持百万字级内容
- AI 对话历史无条数限制
- FTS5 全文搜索在 100MB 级数据集上 < 500ms 返回
- 灵感搜索（五层并发）< 2 秒（不含 AI 精排）

## 9. 技术考量

### 9.1 数据库设计要点

- SQLite WAL 模式，支持并发读
- FTS5 全文索引覆盖所有文本层
- 定期自动备份（可配置间隔）
- 支持拼音搜索（通过自定义分词器或辅助表）

### 9.2 AI 层设计要点

- Provider 接口抽象，新增 AI 服务只需实现接口
- 上下文窗口管理：自动估算 token，超出时智能摘要压缩
- 流式响应通过 Electron IPC 推送到渲染进程
- Prompt 模板系统：用户可创建/编辑/分享

### 9.3 文学数据打包

- 公版文本以预处理后的 SQLite 数据库文件形式打包在应用资源中
- 首次启动时复制到用户数据目录
- 支持增量更新
- 用户可选择不安装某些层以节省空间
