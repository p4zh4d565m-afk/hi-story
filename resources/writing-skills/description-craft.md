# 描写手艺：呈现、感官与删减

## 何时用

环境或人物只有结论没有画面；段落删掉后剧情毫无损失；视觉描写过度；背景只是布景。

## 原文锚点（R）

> 在小说创作中，将呈现和叙述相结合，但是，呈现要多过叙述。（《描写与背景》CH4）
>
> 当传递了故事中许多事物的真实感受之后，读者才会真正融入其中。（CH5）
>
> 任何不能直接推动小说发展的内容都是多余信息，需要删除。（CH11）

## 核心规则（I）

1. 呈现多过叙述：关键画面让读者亲历，摘要与过渡留给叙述。
2. 五官绘图：视觉、听觉、嗅觉、味觉、触觉加第六感；视觉最易滥用，嗅觉最怀旧，声音的缺失也是声音。
3. 人物描写不是外貌清单：先写动机，再挑能体现性格/处境的行为、物件、类比或台词。
4. 描写是预算：提示词能不用就不用、少用副词；清俗语、重复、说教、被动语态；最好的描写有时是不描写。
5. 背景必须干活：塑造人物、突出主题、传递基调、激化矛盾；不干活的背景段删掉。

## 执行（E）

1. 每段标“呈现/叙述”，关键情节点优先改写为可见行为与感官细节。
2. 每场景选 2-3 个感官通道；视觉每段最多一个奇词。
3. 人物出场选 1-2 个能体现动机的细节，禁止五官全列。
4. 按提示词、副词、俗语、重复、说教逐项扫一遍；删下的段落移入备用库。
5. 背景过“换地方剧情会不会变”测试，不会就重写或删除。

## 边界（B）

- 呈现多过叙述不是消灭叙述；节奏、过渡、时间跳跃必须叙述。
- 少用不是禁用；例外要有效果才留。
- 流行小说读者要画面更要情节，描写别拖慢故事。

## 句子层张力（贝尔增量）

**核心**: 句法层制造紧张：刺激-反应成对、主动语态、短句断奏、删副词/感叹号/分号；这不是修辞偏好，是让读者“不颠簸”的机械检查。

**步骤**:
1. 检查刺激-反应链：有反应无刺激、有刺激无反应都标红。
2. 被动语态改主动，对话副词删光，感叹号换成反应节拍。
3. 高潮段改用短句和句号；叙述段保留节奏变化。
4. 删掉“很”类弱化词，用可见行为补强度。

**边界**: 抒情段落可保留长句；句子层检查放在结构和场景问题修完之后。

> “删掉‘很’，感叹号换反应节拍，高潮用短句。” — 贝尔
