# 人物

> 23 组方法模块的合并版（新增《人设心理学》的人格、认同与关系模型）。先建欲望与动机链，再查真相、维度、卡司，最后管理背景与心理深度。
> 并列灵感：麦基“压力选择”、科比特“防御/创伤/秘密”、荣格“面具/阴影/整合”三套底层模型并列呈现，标注来源供选择或组合。

## 路由

- 主角没行动力/成长弧变数值爬升 -> **CH1 欲望与动机链**
- 温柔人设不崩/洗白黑化 -> **CH2 人物真相与两难**
- 工具人/单面/标签反差 -> **CH3 维度与矛盾**
- 群像/配角分不清/抢戏 -> **CH4 卡司与配角系统**
- 人设卡和正文脱节 -> **CH5 人物宝典与场景化传记**
- 没有灵感/人物老套 -> **CH6 人物生成与采访**
- 过去什么时候揭晓 -> **CH7 背景挖掘与冰山**
- 纸片人但说不清差哪 -> **CH8 五基础总检**
- 强到没人疼/没弱点 -> **CH9 脆弱、羞耻与联结**
- 黑化堕落/救赎疗愈 -> **CH10 防御机制与黑化/救赎**
- 心魔写不具体 -> **CH11 幽灵、亡魂与心魔外化**
- 升级流想转型 -> **CH12 成长与转变**
- 主角被骂工具人没意思 -> **CH13 主角平淡诊断**
- 配角没记忆点 -> **CH14 关键细节与怪癖**
- 高大全/玛丽苏/主角假 -> **CH15 面具、阴影与投射**
- 四人团总工具化 -> **CH16 群像即心理系统**
- 心魔成瘾/命运重复 -> **CH17 阴影四力与命运循环**
- 委屈憋太久不知怎么爆 -> **CH18 冲突外显与成长四力**
- 废柴觉醒像开挂/道心空话 -> **CH19 整合弧、当下与本心**
- 系统人格坐标/角色偶尔 OOC -> **CH20 大五人格定位与一致性**
- 主角不讨喜/读者不共情 -> **CH21 读者认同与首因**
- CP 没火花/群像关系单调 -> **CH22 关系环与化学反应**
- 配角太薄或抢戏 -> **CH23 配角复杂度预算**

## CH1 欲望与动机链

**核心**: 动机（为什么）-> 愿望（想要的状态）-> 目标（具体可行动）；主角要有自觉 + 不自觉双层欲望；外在目标必须具体到可见的象征物，并能从五种欲望冲突模式里选一种当故事发动机。

**步骤**:
1. 各写一句自觉欲望与不自觉欲望，且两者不同。
2. 补动机根：分别回答“为什么”和“往哪去”。
3. 按价值观 -> 抱负 -> 故事目标三层检查，缺底层则上层全飘。
4. 欲望平淡就从五种模式选一种重构：冲突改变欲望 / 两种不可调和欲望 / 意识与无意识矛盾 / 目标最终无价值 / 所得非所求。
5. 动机克制扫描：删掉“因为所以”式解释旁白，动机拆成多因素，不归因单一词。

**边界**: 无敌流主角可用趣味线代替成长线；工具型角色只需可见目标。

> “外在目标承载深层需求；欲望必须达到失去即死亡的强度。” — 科比特 / 麦基

---

## CH2 人物真相与两难

**核心**: 人物 = 人物塑造（可见面具）+ 人物真相（压力下的选择）；真相只能通过有代价的两难选择暴露。

**步骤**:
1. 写两栏：人物塑造 vs 人物真相，至少一处明显落差。
2. 设计 3 个递进压力场景：小代价 -> 大代价 -> 终极两难。
3. 反查 OOC：已写选择是否符合人物真相。
4. 关键章改写成“必须 A/B 二选一”的结构。

**边界**: 喜剧角色靠盲目痴迷，不给两难；龙套只需标签。

> “人物真相只能通过两难选择来表达，人物塑造只是面具。” — 麦基

---

## CH3 维度与矛盾

**核心**: 复杂度来自可辨识的矛盾结构；反差要按深度分层（物理/社会/道德/秘密/意识无意识），并扎根背景故事，否则只是标签。

**步骤**:
1. 写 3 组“表面特质 vs 相反特质”。
2. 给每组反差定深度层，越深层越有戏。
3. 为反差补成因场景：他为什么既温柔又冷酷，哪件事让他学会伪装。
4. 高压锅测试：压抑面是否会在高压下喷发。
5. 喜剧角色反向操作：收敛为盲目痴迷。

**边界**: 龙套给标签即可；反差不能只是概念，必须有来处和爆发点。

> “反差有了来处，标签就变成人格。” — 科比特

---

## CH4 卡司与配角系统

**核心**: 卡司是互相定义的关系系统；配角按功能类型分配（幽灵/亡魂/抗衡者/盟友/背叛者/群众），功能之外再给独特性；每个主要人物像乐器一样有鲜明声部，合奏目的就是制造冲突；删掉他没人受损就是标签人。

**步骤**:
1. 画关系轮轴：谁定义谁的哪一面。
2. 按功能分配配角：过去包袱、推动真相、拉回旧生活、支持映照、先建信任再反转、承载社会压力。
3. 删除测试：删掉后无人受损的角色待重设计。
4. 喧宾夺主检查：是否抢走高潮焦点。
5. 为每对定义关系写一个能激活对方维度的场景。
6. 声部编曲：每人写语音日记和“五件大事”，用人物网格从过去/现在/未来找剩余冲突点。

**边界**: 双人极简只写对照；系统文 NPC 给功能即可。

> “配角在功能之外再给一项独特性与自己的需求。” — 科比特 / 麦基

## CH5 人物宝典与场景化传记

**核心**: 外部、性格、环境、心理四区档案；卡上每个字段都必须能改写成影响行为的场景问题，不留死词条。

**步骤**:
1. 为每个主要人物建四区档案。
2. 字段转场景：外表 -> 一场被区别对待的戏；恐惧 -> 勇气度量压力戏；关系 -> 最快乐/最恐惧/最羞愧/最宽恕的时刻。
3. 写场景细节前先查档案，不凭记忆；随写随更。

**边界**: 档案是工具不是交付物；卡上答不出的经历要么补背景要么删特征。

> “人物卡上不留一个不能变成场景的词条。” — 科比特 / 英格曼森

---

## CH6 人物生成与采访

**核心**: 从故事/潜意识/艺术自然/真人/复合角色五源生成人物；复合人物必须经受经历检验；再用百问采访让潜意识替人物回答。

**步骤**:
1. 五源采集：真人关系清单、照片音乐新闻、梦境记录、故事大纲倒推、复合合成。
2. 经历检验：每个特征追问“这个特质从什么经历来”，答不出就补背景或删特征。
3. 百问采访（恐惧、秘密、口头禅、最尴尬时刻、心魔），人物不配合就自由采访。
4. 九型人格只做词汇确认，不生搬框架。

**边界**: 龙套不用采访；采访产出是素材，不是正文。

> “复合人物不是拼脸拼性格，必须通过经历检验。” — 科比特 / 维兰德

## CH7 背景挖掘与冰山

**核心**: 从激发事件倒挖人物过去，找“点金石”作动机锚；使用时线索早给、揭示最晚、篇幅最短。

**步骤**:
1. 从激发事件倒问：他过去的哪些经历让他这样回应。
2. 找一块点金石（改变人生的关键事件）。
3. 冰山使用：尽早给线索，等到缺它不可时再揭示，篇幅越短越好。

**边界**: 作者知道十倍，给读者的只能一点点；流水账小传无效。

> “背景故事像大蒜：作者知道十倍，给读者一点。” — 英格曼森 / 维兰德

---

## CH8 五基础总检

**核心**: 戏剧化人物五基础：欲望、受阻+计划、表面矛盾、意外/犯错并受伤、秘密；五查过完再润色。

**步骤**:
1. 欲望：想要什么，是否具体到可见目标。
2. 受阻+计划：有没有障碍与对策。
3. 表面矛盾：有没有与身份冲突的细节。
4. 意外/犯错/受伤：有没有让他付出代价的失误。
5. 秘密：有没有“抽泣”式更深困境。

**边界**: 五基础是诊断试金石，不是静态人设清单；缺哪项补哪项。

> “五个基础逐项问诊，缺哪项补哪项，五查过完再润色。” — 科比特

## CH9 脆弱、羞耻与联结

**核心**: 强大是外在能力，脆弱是内在联结；羞耻源于联结断裂恐惧，人物需要一个“怕失去谁”的具体对象和值得被爱的证明场景。

**步骤**:
1. 给主角一个具体对象：“怕失去谁”。
2. 写羞耻源场景：公开出丑、被抛弃、秘密暴露的恐惧。
3. 写值得被爱的证明：他必须为某人暴露弱点并承担后果。

**边界**: 能力可以强，联结不能断；纯独狼爽文可弱化但会少共情。

> “说服力来自挣扎而非讨喜；羞耻=害怕被群体抛弃。” — 科比特

---

## CH10 防御机制与黑化/救赎

**核心**: 给人物定防御层级基线，压力场景让防御降级；病理性策略（着迷/成瘾/否定/自残）是戏剧富矿，恢复必须展示挣扎。

**步骤**:
1. 定平时防御层级（成熟应对：升华/幽默）。
2. 设计压力场景让防御逐级降级：压抑/理智化 -> 否定/投射 -> 幻想/自欺。
3. 黑化给“欺骗+懦弱”两个成分：假装没事 + 不敢面对。
4. 救赎写挣扎与反复，不一步洗白。

**边界**: 病理性策略不是贬义标签，是用来写机制的素材。

> “疗愈故事中主角与对手是同一个人的结构。” — 科比特

## CH11 幽灵、亡魂与心魔外化

**核心**: 把心魔拆成两个角色：幽灵 = 承载过去创伤的人，亡魂 = 迫使主角现在面对真相的人；内心戏就有了对手和场景。

**步骤**:
1. 找幽灵：死去的恩人、背叛的旧友、缺席的父母，决定主角的回避行为。
2. 找亡魂：救赎对象、新盟友甚至对手，推动主角转变。
3. 设计幽灵/亡魂同时出现在场上的关键场景。

**边界**: 无过去创伤的主角可不做；心魔外化不等于鬼故事。

> “让主角与幽灵的关系决定回避，让亡魂的出现推动转变。” — 科比特

---

## CH12 成长与转变

**核心**: 成长 = 深挖/加速（强化特质），转变 = 拆墙/调向（否定旧我）；主角三问决定主线类型。

**步骤**:
1. 用三问定型：能得到吗（外驱升级）/ 我是谁（身份揭露）/ 要改什么（救赎成长）。
2. 判定当前主角在走哪条线，再决定下一大卷的冲突类型。
3. 成长强化特质，转变换一套活法，两者可相交但别混写。

**边界**: 单元剧可用成长循环；转变需要亡魂或等价的外部推力。

> “成长是深挖，转变是拆墙；两个有交集的圆。” — 科比特

---

## CH13 主角平淡诊断

**核心**: 主角平淡按症状查根因：欲望强度、主动计划、内外联结、美德化身、作者替身、对手适配、焦点分裂。

**步骤**:
1. 欲望够不够强（失去即死亡）。
2. 有没有主动计划和反击，不是被动接招。
3. 外在目标与内在需求是否联结。
4. 是否美德化身（给错误+代价）。
5. 是否作者替身被豁免痛苦。
6. 有没有真正适合他的对手。
7. 多线/多主角是否焦点分裂。

**边界**: 共鸣比讨喜重要；反思、悔恨、幽默可调和单薄。

> “主角被骂工具人，从七查定位，改完再让读者复测。” — 科比特

---

## CH14 关键细节与怪癖

**核心**: 怪癖/口头禅/坏习惯必须与深层孤独或脆弱呼应，否则只是喜剧噪音；一个有效关键细节胜过一打装饰。

**步骤**:
1. 给角色选一个与深层特征呼应的表层习惯（紧张摸头发、旧物护身符、特定口头禅）。
2. 让它在关键时刻泄露出秘密或脆弱。
3. 克制扫描：堆三个无关怪癖就删。

**边界**: 喜剧向可弱化主角式怪癖；反派可用怪癖增强压迫或可悲。

> “怪癖必须指向孤独本性，否则沦为喜剧噪音。” — 科比特

---

## CH15 面具、阴影与投射

**核心**: 人格面具是防御壳（生存/安全/归属/价值四类），阴影是被禁闭的能量（死亡/危险/排斥/卑劣四类）；撕面具要分阶段，强烈好恶 = 投射信号。

**步骤**:
1. 写人物卡：需求 -> 面具 -> 阴影配对。
2. 找第一个破绽：安全面具在“失去控制”场景里失效，阴影泄漏。
3. 投射检测：主角最厌恶的反派特质，正好是主角自己压抑的阴影。
4. 四型诊断扫章节：大量停留在面具层（好运、无代价、无内在冲突）就补阴影泄漏。

**边界**: 纯工具角色不需要完整阴影；喜剧角色可只做面具痴迷。

> “面具是防御壳，阴影越压制越强；强烈好恶是投射信号。” — 童欣《光影荣格》

---

## CH16 群像即心理系统

**核心**: 所有角色 = 主角一个心灵的投射：道侣承载归属面具，宿敌承载阴影，挚友承载软弱或本心；每次互动 = 内在能量的谈判。

**步骤**:
1. 为主角心理地图分配角色：面具、阴影、本心、成长面。
2. 给每个角色一个心理必然性，不靠互补标签。
3. 宿敌关系问：他承载了主角哪部分压抑的自我。
4. 群像冲突问：这场戏在谈判哪两种内在能量。

**边界**: 极简双人文只做面具/阴影两轴；系统文 NPC 可保留功能位。

> “连反派的出现都有内部根源，群像张力来自心理必然性。” — 童欣《光影荣格》

---

## CH17 阴影四力与命运循环

**核心**: 阴影四力：操控（阴影控制他人）、反噬（压制反弹）、诱惑（禁果更甜）、复制（代际传递）；命运循环 = 自动化行为在同样情境重复同样选择。

**步骤**:
1. 列人物自动化行为：同样情境自动做同样选择。
2. 找情结源头事件。
3. 用阴影四力设计剧情形态：禁令制造诱惑与代价。
4. 破局：在旧选择发生前一秒插入觉察节点，用新行动打破循环；外境转变跟在内境转变之后。

**边界**: 重生文“知道未来”不等于破局，缺情结觉察仍是循环。

> “改变的是信息不是情结；自动化行为 -> 情结源头 -> 觉察节点 -> 新选择。” — 童欣《光影荣格》

## CH18 冲突外显与成长四力

**核心**: 内隐冲突按“小破绽 -> 试探性表达 -> 正面冲突 -> 抱持承接 -> 整合选择”外显；成长四力 = 意愿、觉察、抱持、实践，缺一步觉醒就是假的。

**步骤**:
1. 给憋屈铺外显节奏，不让冲突一次性爆炸。
2. 冲突期最危险：没有抱持资源时，爆发等于毁灭。
3. 用四力查成长：真想改变吗、看见旧模式了吗、接得住羞耻恐惧吗、在现实行动了吗。
4. 表达情绪不等于被情绪操纵，攻击性表达要落在行动上。

**边界**: 纯爽文可用外显暴力代替抱持，但会少心理深度。

> “冲突期最危险，无抱持即毁灭；成长四力缺一步，觉醒就是假的。” — 童欣《光影荣格》

---

## CH19 整合弧、当下与本心

**核心**: 整合七步让面具与阴影和解，允许反复与混合；破幻境靠回到当下真实细节，不靠更强幻想或镇压；本心 = 无好处也愿做 + 做完有充实感。

**步骤**:
1. 设计整合弧：面具破碎 -> 谈判 -> 整合，主角先完成再辐射配角。
2. 心魔幻境：写身体感受、眼前动作、责任，让两界在当下整合。
3. 本心检验：无好处也愿做 + 做完有充实感；有益处驱动的行为属于面具层。
4. 配角的转变来自体验，不是主角的话术。

**边界**: 无成长线的人物不做整合；仙侠“道心”可用本心检验量化。

> “两界都不真实，整合的当下才真实；道心失守 = 为利益驱动、做完空虚。” — 童欣《光影荣格》

## CH20 大五人格定位与一致性

**核心**：复杂人物不是多贴标签，而是给外向、亲和、尽责、神经质、开放五个维度配置可观察的行为证据；反常行为必须通过情境、时限、背景、重复模式四查。

**步骤**：五维各写低/中/高及行为证据；关键人物细化最突出的 1—2 维；保留少数极端点。对 OOC 风险逐项确认触发情境、持续时间、背景原因和是否形成可识别模式。

**边界**：背景板不必全检；人格是倾向，不是禁止例外的铁律。

## CH21 读者认同与首因

**核心**：主角首次关键出场用可信、相似、道德正面、幽默/诚实四条路径建立认同；越线行为需要好出发点、补偿品质、背景或后果。

**步骤**：首章至少命中四项中的三项；检查前三个关键行为会形成什么道德印象；为重大越线节点保留理解窗口，但不替角色免除后果。

**边界**：作品若明确承诺恶人主角的反道德爽感，不强行洗白。

## CH22 关系环与化学反应

**核心**：用控制（强势—顺从）×交流（温暖—敌对）定位关系底色；用相似性解释靠近，用差异互补制造张力，用长期兼容维度设计维持或破裂。

**步骤**：给主要角色标关系象限；每对关键关系写相似基础、互补收益和断裂点；关系改变时让坐标移动并影响其他互动。

**边界**：纯功能搭档不必恋爱化；心理统计只作构思工具。

## CH23 配角复杂度预算

**核心**：配角写多深由笔墨决定。背景板用 1—2 个突出维度；常驻配角用 2—3 个维度并有动机信念；重要配角可到 4—5 维。

**步骤**：按出场频率分级；检查同组人物在维度、目标或信念上至少有一项差异；给持续出场的配角补一句动机和一句信念。

**边界**：一次性功能角色允许扁平，不为“全面”强行加戏。

## 组合使用

- 与 `dialogue-craft` 组合：维度、关键细节与专属声音确定后，角色不再同声。
