# 前提与定位

> 7 组原子 skill 的合并版。执行前先路由到模块；开书阶段建议按 P1 -> P3 -> P2 的顺序跑。

## 路由

- 有模糊创意要成型 -> **P1 前提工程**
- 写简介/安利/一句话 -> **P2 一句话概括**
- 写给谁/怕没读者 -> **P3 目标读者窄众**
- 目标模糊/不知好小说长什么样 -> **P4 完美评述**
- 想反转又怕为反而反 -> **P5 读者期待反转**
- 两个创意拿不定 -> **P6 身体直觉初筛**
- 没灵感/只有一个平庸点子 -> **P7 假如构思生成器**

---

## P1 前提工程

**核心**: 从“如果 X 会怎样”问句出发，压成涵盖人物、背景、主要冲突的前提句；前提句是方向试金石。

**步骤**:
1. 列 10+ 个“如果”问句，写下来不许只过脑。
2. 挑最戳的一个，提炼前提句（人物 + 背景 + 冲突）。
3. 潜能三问：这个前提还能走多远？能否推到双世界级反转？反转是否符合人物逻辑？

**边界**: 单元剧/情绪流可用一句体验承诺代替前提句。

> “前提句是试金石：若一句话装不下人物、背景、主要冲突，说明想法还没成型。” — 维兰德

---

## P2 一句话概括

**核心**: 不超过 25 词、一到两个主人公、具体可感任务、不泄底；是给目标读者的钩子，不是给编辑的完整大纲。

**步骤**:
1. 写“某人想要什么，但有什么障碍”。
2. 砍到 25 词内，只留一个主任务。
3. 泄底测试：删掉结局信息后钩子仍成立。
4. 读者测试：这句话让人想追问吗。

**边界**: 给编辑的简介可以泄底；平台简介可放宽字数。

> “一句话概括是不泄底的卖点句，必须让目标读者立刻决定要不要听更多。” — 英格曼森

---

## P3 目标读者窄众

**核心**: 按心理状态（想体验什么）定义尽可能小的读者群，越窄越容易精准取悦和口碑扩散。

**步骤**:
1. 写“喜欢 X 类型、想体验 Y 情绪、反感 Z 桥段的人”。
2. 把这句话当所有决策的过滤条件。
3. 情节、人物、节奏选项逐一过筛。

**边界**: 平台算法需要宽标签时，窄众定义仍是内容取舍的基准，不是分发标签。

> “先按心理状态选一个尽可能小的群体，精准取悦窄群体才可能产生口碑扩散。” — 英格曼森

---

## P4 完美评述

**核心**: 动笔前假装理想评论家给目标作品写一篇具体、全面、尽情夸的评述；夸出来的内容就是任务清单。

**步骤**:
1. 分情节、人物、主题、高潮逐项写好评。
2. 每项具体到“第几章做了什么”。
3. 与现状对照，差距即优先级。

**边界**: 完美评述是目标设定，不能替代读者反馈；边写边更新。

> “写你的完美小说：先写一篇理想评论，再把它变成提纲的任务清单。” — 维兰德

---

## P5 读者期待反转

**核心**: 先列目标读者对题材的标准期待，满足大部分，只选 1-2 项在关键节点违背；反转锚点来自清单本身。

**步骤**:
1. 列 6-10 条读者默认期待（系统文主角一路爽、反派死于话多等）。
2. 划掉最多 2 条要违背的。
3. 提前铺线索，让违背有铺垫。
4. 验证：其余期待照常满足。

**边界**: 全部颠覆等于背叛读者；违背项必须服务于主题或人物，不能只为意外。

> “反转的锚点来自清单本身，所以读者既意外又不觉得背叛。” — 维兰德

---

## P6 身体直觉初筛

**核心**: 用身体反应初筛创意：哪个让你心跳加速、喘不过气、想马上写，哪个优先投入。

**步骤**:
1. 把候选创意逐个念出来。
2. 记录身体反应（心跳、呼吸、兴奋感）。
3. 只把身体有反应的 2-3 个送进 P1。
4. 之后仍用左脑逻辑复核。

**边界**: 直觉只是初筛，不能替代前提检验和结构验证。

> “技法完美但身体没反应的点子降权；先打动自己才能打动读者。” — 维兰德

---

## P7 假如构思生成器

**核心**: 从任何触发物连续问“假如……会怎么样”，强制写到 5-10 个；每个构想都要推向主角命运和反方动机，最后几个搜肠刮肚的通常最好。

**步骤**:
1. 任意触发物开始，连续追问“假如……会怎么样”。
2. 强制写到 5-10 个，不许在第三个就停。
3. 每个构想绑定主角命运与反方动机，删除只换场景不换命运的点子。
4. 选最兴奋的送 P1 前提工程；字典游戏可随时重启。

**边界**: 量产是第一步，P1-P6 负责筛选；不要用“灵感”代替数量。

> “数量强制 + 最后几个最好 + 每个构想绑主角命运和反方。” — 贝尔

## 组合使用
