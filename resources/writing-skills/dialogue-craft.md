# 对白

> 10 组原子 skill 的合并版。执行前先路由到模块；对白打磨通常需要多个模块按序跑。

## 路由

- 台词在聊天/没推进/谈判/内心独白 -> **D1 说即是做**
- 整体检查“差一点但说不清差在哪” -> **D2 六项任务**
- 太直白/话里有话/嘴硬心软 -> **D3 潜文本冰山**
- 角色同声/不看名字分不清 -> **D4 专属声音**
- 假/尬/空/背书/重复 -> **D5 瑕疵诊断**
- 角色在讲设定/像说明书 -> **D6 展示而非讲述**
- 吵架/喜剧/权谋/暧昧腔调单一 -> **D7 冲突形态**
- 太满/太煽情/要删字 -> **D8 少即是多**
- 对白水/像答题/口头网球 -> **D9 对话现实感**
- 对话像闲聊/要当场张力 -> **D10 冲突对话工具箱**

---

## D1 说即是做

**核心**: 每句台词都是言语行动（请求、拒绝、试探、威胁…），行动/反应构成节拍，推动场景。

**步骤**:
1. 给每句台词标注言语行动，标不出“闲聊/说明”的删掉或改动作。
2. 连成行动链：A 行动 -> B 反应 -> A 反制。
3. 两端回填场景欲望：每句都能回答“帮谁靠近什么”。
4. 朗读一遍，删掉所有不执行行动的句子。

**边界**: 问路/点餐等工具对白不用行动化；诗化独白允许语言大于行动。

> “对白是一种行动，每句台词都在执行欲望。” — 麦基

---

## D2 六项任务

**核心**: 好对白同时达标六项：内在行动、节拍推进、信息传达、角色个性化、抓住注意、可信。

**步骤**:
1. 逐句标行动。
2. 画节拍链，看是否推向转折。
3. 抽查信息冗余与“抽名可辨”。
4. 朗读按注意与可信打分，六项不齐就标注待修项。

**边界**: 诗歌/唱词权重不同；故事病没修好时先不跑此清单。

> “有效的对白能同时执行六项任务。” — 麦基

---

## D3 潜文本冰山

**核心**: 台词下有三层：说出口的、意识到但藏住的、自己都说不出口的；冰山技巧 = 大量内容压进潜文本，文本只露尖端。

**步骤**:
1. 写三层底稿：他说出口的 / 他藏住的 / 他自己都不知道的。
2. 设计错位：嘴在拒绝、动作在靠近；措辞在夸、语义在贬。
3. 删直白：所有“把心里话直接说出”的台词改为间接表达。
4. 读者验证：复述的内容应深于字面。

**边界**: 儿童文学要字面清晰；喜剧笑点不要过度藏。

> “最内核是说不出口的，中层是没说出来但意识到的，外层才是说出的话。” — 麦基

---

## D4 专属声音

**核心**: 专属对白从词汇层开始：词库、句法、句长、节奏、言语策略；语言三件套 = 措辞节奏 + 世界观 + 态度；抽名测试是验收标准。

**步骤**:
1. 每人建词库：常用词、禁用词、句长偏好、不超过 2 个口癖、比喻来源。
2. 写态度说明书：固执/不耐烦/宽容/忧郁，同一句话按不同态度改写三版对比音色。
3. 同题异声：同一情境让 3 个角色各说 3 句。
4. 抽名测试：遮掉说话人归因，成功率应不低于 90%。
5. 失败句回填差异，再测。

**边界**: 叙述者旁白可统一；极简风格靠行为差异。

> “每个角色仿佛有他个人的独特字库。” — 麦基

---

## D5 瑕疵诊断

**核心**: 四类病层按序查：可信性（空洞字眼/滥情/过于明白）-> 语言（陈词滥调/角色中立）-> 内容（写在鼻子上）-> 设计（重复节拍）。

**步骤**:
1. 先查可信性：这句谁需要听到？动机是什么？
2. 再查语言：标出陈词滥调与中立表达。
3. 查内容：潜文本是否被写成文本。
4. 查节拍链：连续两组相同行动就重新指定行动，不要只换词。

**边界**: 故事结构病先修结构；玩梗对白区分“无意识陈词”与“有意玩梗”。

> “空洞、虚假的对白，并不能因为自然写实而得救。” — 麦基

---

## D6 展示而非讲述

**核心**: show 不是加描写，而是信息在角色为欲望奋斗时自然泄漏；tell 是角色停下来替作者说话。

**步骤**:
1. 圈出所有“角色停下来说明”的段落。
2. 找欲望挂钩：这段信息现在被谁需要、用来达成什么。
3. 弹药化重写：A 拿信息进攻/防守，B 反应。
4. 闪回审查：闪回是否改变当下价值判断。

**边界**: 第一人称叙述者的总结是文体；系统面板等平台功能可直给。

> “连闪回蒙太奇也可能是在 tell，只有把解说变成斗争武器才算 show。” — 麦基

---

## D7 冲突形态

**核心**: 六种几何结构各有对白语法：均衡、喜剧（盲目痴迷）、不对称、非直接、自反、微限；先定形态再写词。

**步骤**:
1. 从六形态里选一种，写选择理由。
2. 定角色姿态：正剧清醒承担风险；喜剧痴迷且盲目；不对称弱势方语言补权。
3. 先写 3 个符合形态的行动/反应节拍，再填词。
4. 同戏异写一个节拍验证选型。

**边界**: 极短对话直接行动化，不必显式定形态。

> “喜剧角色像近视一样死咬眼前欲望，看不见风险。” — 麦基

---

## D8 少即是多

**核心**: 字面少、含义多；删掉把情绪说破的句子，读者自行补足；同一情感效果重复第三次会反噬。

**步骤**:
1. 删解释层：所有“我很害怕/我怕失去你”式说破句。
2. 关键情感拍压缩到 10 字以内单句；删到读不懂就补可见行为。
3. 消灭法则扫描：重大情绪效果全书只出现 1 次或升级出现。
4. 朗读对比新旧版，确认更短版情感更重。

**边界**: 谈判戏删字不能删信息；喜剧语言游戏不在删字之列。

> “能砍的字就砍，尤其当砍了它可以增加对白之效果。” — 麦基

---

## D9 对话现实感

**核心**: 对话要像真实而非真实；先写潜台词表（每个人在这段话里真正想要什么），再删掉句句接应的口头网球，用节拍替代标签。

**步骤**:
1. 写潜台词表：说服、试探、回避、抬高、求饶。
2. 删口头网球：让人物答非所问、转换话题、不听答案，各自推进目标。
3. 删解释性旁白，用节拍（动作、环境、沉默）传达语气。
4. 标签只用“说”，副词交给对话本身。
5. 每句检查：是否同时完成推进、信息、性格三件事。

**边界**: 纯信息对白不套此规则；喜剧需要故意的口头网球时例外。

> “潜台词是沉默背后的风暴；节拍替代标签，副词交给对话。” — 科比特

---

## D10 冲突对话工具箱

**核心**: 给每人一个当场要达成且互斥的盘算；把直接回应改成侧闪（无关陈述/以问代答/沉默/动作回应）；必要时把对话当武器。

**步骤**:
1. 写每人盘算：三个动机混搭，两个互斥。
2. 直接回应改侧闪：无关陈述、以问代答、需要解释的话、沉默、动作回应。
3. 用武器句式压制对方：最尖锐的词留给最关键处。
4. PAC 检查：父母-成人-孩子角色切换是否在拉扯关系。
5. 修订时每人有需求，删掉没有盘算的台词。

**边界**: 信息交换场景不用互斥盘算；喜剧可用侧闪制造错位笑点。

> “盘算三动机混搭、侧闪四式、PAC 角色切换是可点名的工具。” — 贝尔

## 组合使用

- 常规打磨流水线：D5 诊断 -> D1/D3 修行动与潜文本 -> D4 修声音 -> D8 收尾删字。
- 与 `story-structure-craft` 组合：场景没价值轴时先修结构，再磨对白。
- 与 `character-craft` 组合：先定人物维度与欲望，再做专属声音和冲突形态。

## 大师写作课增量（2026-08-26）

- 动力之轮：每条台词至少推进剧情/揭示人物/改变关系/制造张力，标不出功能就删。（《人物对话》CH4）
- 三线编织：对话与叙述、行动交替，避免通篇问答。
- 张力三层：心理、言语、肢体冲突可叠加；开篇尽快放第一处摩擦。
- 错误扫描：反复直呼其名、满屏提示词、副词贴“说”；提示词能不用就不用、少用副词。
- 节奏：对话当刹车或油门，加速用短回合与打断，减速用反应与沉默。
