# 场景工程

> 9 组原子 skill 的合并版。单场戏先选主动/被动骨架，再跑价值翻转验收。
> 并列灵感：麦基价值翻转、英格曼森场景考验、大师写作课四和弦/热点、科比特六要素、贝尔三O 是不同检查视角，并列呈现；“结果更糟 vs 胜利结尾”两种默认值都保留。

## 路由

- 章末/场景末没变化 -> **SC1 价值翻转**
- 这场景到底在考验什么 -> **SC2 场景考验**
- POV 有目标但进展弱 -> **SC3 主动场景**
- 主角受挫后不知怎么写 -> **SC4 被动场景**
- 困境像伪选择/决定不动 -> **SC5 困境与决定**
- 拿不准删不删这场 -> **SC6 多米诺取舍**
- 世界观/前世设定怎么给 -> **SC7 解说释放**
- 日更章节被说水 -> **SC8 场景六要素**
- 中段拖/要快慢节奏 -> **SC9 场景三O**

---

## SC1 价值翻转

**核心**: 场景成立的唯一标准是押上台面的价值发生正负翻转，变化来自主角行动引发的意外反应。

**步骤**:
1. 给场景写一对成对价值（信任/怀疑、地位升/降、爱/恨）。
2. 找转折点：用“他以为 A，结果 B”概括。
3. 验证四重效果：惊奇、好奇、见识、新方向。
4. 无翻转场景降级为过渡或删除。

**边界**: 留白/氛围场景可有意不翻转；日常发糖章改用关系亲疏轴。

> “一个场景即是一个缩微故事，转折的是负荷着价值的情境。” — 麦基

---

## SC2 场景考验

**核心**: 场景考验 = 占据整个场景、结尾被打破、下一场换新的单场难题；先问“POV 在求什么、结尾是否打破考验”。

**步骤**:
1. 给场景写一句可指名的考验。
2. 检查考验是否占据全场景、结尾被打破。
3. 发糖章按“是否推进关系考验”决定留删，不按甜度。

**边界**: 日常文可压缩成叙事概要，不一定写成完整场景。

> “没有考验的场景判‘差’，考验只活一个场景。” — 英格曼森

---

## SC3 主动场景

**核心**: 主动场景 = 目标 -> 冲突 -> 挫折；目标必须具体、可拍摄、有难度、符合人物。

**步骤**:
1. 给 POV 写可拍摄目标（不是“获得幸福”）。
2. 目标五条件：场景时间、可实现、有难度、符合人物、具体客观。
3. 冲突循环：努力 -> 受阻 -> 再努力，逐轮升级。
4. 结尾短促挫折，留钩。

**边界**: 谈判、文戏同样适用；打斗只是素材不是场景。

> “打斗章没进展，大概率缺目标、冲突循环和挫折结尾。” — 英格曼森

---

## SC4 被动场景

**核心**: 被动场景 = 反应 -> 困境 -> 决定；情绪反应与挫折成正比，困境无好选项，决定必须开始行动。

**步骤**:
1. 先写符合人物的情绪反应，不堆情绪词。
2. 困境：逐条排除好选项，只留最不坏。
3. 决定：成为下一主动场景的目标，并全力践行。
4. 可压缩成总结或跳过，但作者心里要有三拍。

**边界**: 被动场景过多会拖节奏；只有刺激没有决定 = 未完成。

> “口头想通只是困境延续，决定必须被全力践行。” — 英格曼森

---

## SC5 困境与决定

**核心**: 真困境 = 每个选项都违背人物一条同等重要的价值观；决定四原则 = 强行开线、成为下场景目标、承认风险、全力践行。

**步骤**:
1. 列出主角所有选项，删除一眼可见的最优解。
2. 每选项写“违背了哪条价值观”。
3. 决定按四原则验收：是否减少对手选择、是否成为下一目标。

**边界**: 伪困境（有明显最优解）会毁掉选择；纯喜剧可不用真两难。

> “真困境建立在人物灵魂矛盾上，只能挑危害最小的选项。” — 英格曼森

---

## SC6 多米诺取舍

**核心**: 小说是多米诺方阵；每场戏都要有存在理由，删掉它后续照常发生就删。

**步骤**:
1. 对每场问“删掉后后续还会发生吗”。
2. 会就删或调整；不会但看似闲笔，检查它是否隐藏骨牌。
3. 保留能扭转高潮的隐藏骨牌，并强化其连接。

**边界**: 单元剧允许独立小骨牌，但整体仍要形成网络。

> “看似闲笔却能扭转高潮的，保留并强化其连接。” — 维兰德

---

## SC7 解说释放

**核心**: 信息最少、最晚、弹药化——只在角色为欲望斗争时泄漏，成为进攻/防守武器。

**步骤**:
1. 列事实清单，按必要性排序。
2. 延迟测试：只有缺失会造成迷惑的事实保留到当前点。
3. 弹药化：A 拿信息进攻，B 反应，信息在攻防中泄漏。
4. 闪回审查：闪回是否改变当下价值判断。

**边界**: 设定附录可直给；系统面板等平台功能可直给。

> “把解说转化为弹药，信息在斗争中被使用而非被宣读。” — 麦基

---

## SC8 场景六要素

**核心**: 结构三要素（设置/转折点/结果）+ 角色三要素（目标/阻碍/行动）；章节结束人物毫无变化就是水章。

**步骤**:
1. 设置：有没有两难或悬念。
2. 转折点：有没有意外事件。
3. 结果：有没有新局面。
4. 角色：他这一章想要什么、谁挡路、他主动做了什么。
5. 验收：失败是否让他向内看，而不是毫无变化。

**边界**: 日常/氛围章可弱化，但要明确是故意选择。

> “六项缺一即补；失败即内省，毫无变化就是水章。” — 科比特

---

## SC9 场景三O

**核心**: 场景最小动力机制 = 行动节拍（目标-障碍-结果，结果默认更糟）+ 反应节拍（情感-分析-决策）；用节拍控制快慢，不是用字数。

**步骤**:
1. 拆行动节拍：目标 -> 障碍 -> 结果，结果让处境更糟。
2. 拆反应节拍：情感 -> 分析 -> 决策，决策成为下一行动节拍的目标。
3. 要快就压缩反应到两三句，要慢就展开反应。
4. 场景结尾检查：是否停在结果或决策的冲击点上。

**边界**: 纯动作章可压缩反应；氛围章可跳过行动节拍但要有意识。

> “三O + 情感-分析-决策给了场景最小动力机制。” — 贝尔

## 大师写作课增量（2026-08-26）

- 场景四和弦：行动、反应、铺陈、深化；行动/反应是主旋律，铺陈/深化是调味。（CH7）
- 场景要素：开头引子、中段紧张、结尾推手。
- 桥段与热点：场景由桥段组成；无热点的场景删掉，热点前废话全清。
